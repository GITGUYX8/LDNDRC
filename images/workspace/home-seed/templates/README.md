# ROS 2 Starter Templates



Folders:

- `ros2-pub-sub/` has a basic publisher/subscriber skeleton.
- `turtlebot3/` has TurtleBot3 simulation starter files.
- `turtlesim/` has beginner turtlesim starter files.
- `examples/` has runnable examples that are separate from the blank templates.

Useful workspace commands:

```bash
cd ~/dev_ws
colcon build
source install/setup.bash
```

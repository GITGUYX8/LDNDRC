# TurtleBot3 Template

Use this folder when working with TurtleBot3 in the minimal workspace.

Start the simulator:

```bash
turtlebot3-sim
```

Other TurtleBot3-provided worlds:

```bash
turtlebot3-sim empty
turtlebot3-sim house
```

Teleop:

```bash
turtlebot3-teleop
```

Common topics:

- `/cmd_vel`: velocity commands sent to the robot.
- `/odom`: odometry feedback from the robot.

The template scripts contain TODOs only. Students should decide what commands to publish and what sensor/odometry data to read.

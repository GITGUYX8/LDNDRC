LDNDRC — you're on the onboarding network

Welcome! This laptop is on the onboarding Wi-Fi, which only reaches the cluster master. To join the ROS 2 simulation cluster, download the enrollment script below, run it on your laptop, and wait for the instructor to approve your request. Afterwards, switch to the cluster network.

1 · Download the enrollment script

Pick the one for your operating system. The file is served from this laptop's master — no internet required.

2 · Run it yourself — downloading is not installing

The script only registers this laptop and waits for approval. It does nothing until you run it.

Linux / macOS: open a terminal in your Downloads folder:

chmod +x joining-cluster.sh
bash joining-cluster.sh

Windows: open PowerShell in your Downloads folder:

powershell -ExecutionPolicy Bypass -File joining-cluster.ps1

If a download or run fails, just retry — re-running is safe: the master recognizes your laptop and reuses the same join request instead of creating a duplicate.

3 · Wait for approval, then switch networks

  1. The script registers this laptop with the instructor console.
  2. The instructor approves or denies your request (the script shows the status live).
  3. On approval the script tries to switch Wi-Fi to the cluster network (nmcli on Linux, netsh on Windows); otherwise it prints the manual steps.
  4. Open control.ros-platform.local once you're on the cluster network.

Counter note: the download numbers reflect files served by this server — they cannot tell whether anyone saved or executed the script. "Requests" (preview probes, partial fetches, retries) are tracked separately from served downloads. The unique-device figure is an estimate based on network address and browser fingerprint; it is not identity and it is spoofable. No personal data is stored: only aggregate counts leave this server, and only instructors can see the detailed statistics.
